Record on hardware

Write the observed values next to each item in the team notes.

  1. Barcode argument count/order. Keep Define nlBarcode on and scan. Is nlBarcode called with four or five arguments? Record every value and type.
  2. Source position. Is the source first, last, absent, or undefined? Record internal scans and Bluetooth scans separately.
  3. Status values. Record successful scans, cancelled scans and any failure status. Note whether status is a string or a number.
  4. Symbology values. Record the numeric ID and the human-readable name for each code type available on the device.
  5. Device info. In the surface table, note whether model, serial, build and device name are plain properties or getter functions, and their exact key spelling.
  6. NFC wedge. With Define nlNFC off, tap a tag while an input is focused. Does the value appear in the field, and does it send Tab or Enter? Repeat with the logger enabled and confirm callbacks replace the wedge.
  7. NHub callback spelling. Turn on Define NHub loggers and trigger a Bluetooth scan. Record which global name appears in the log, either nlNHubResult or nlNHubRestult, plus the raw arguments.
  8. URL options and version. Copy the Page URL fact above and record which options were accepted (:ALLOWZOOM, :NOBUTTONS, :AUTOFOCUS). Use navigator.userAgent and the surface table to note any way to infer the Web Kiosk version.
  9. Method casing. Use the casing buttons above and record which of TriggerMode and Triggermode exists. Method buttons and arbitrary calls also retry camelCase, all-lowercase and all-uppercase spellings.
